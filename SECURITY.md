\# Security Policy



\## Supported Versions



This project is currently maintained as a portfolio and educational application.



\## Reporting a Vulnerability



If you identify a security issue, please do not publish sensitive details in a public issue.



Instead, report the vulnerability privately to the repository owner.



Do not include:



\- real credentials;

\- API keys;

\- private tokens;

\- personal information;

\- production incident data.



This application is intended for local development and educational use.
